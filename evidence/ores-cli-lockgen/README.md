# ores-cli AST helper lock closure test evidence

This directory mirrors only the dependency manifests needed to reproduce the four AST-helper lockfiles required by `ORESoftware/ores-cli` source-audit admission.

The lockfiles were generated by the pinned hosted toolchains in `.github/workflows/ores-cli-ast-lock-closure.yml`. Once materialized, every later hosted run must regenerate them byte-for-byte with no staged lockfile delta.

`ORES_CLI_SOURCE_SHA` records the private source candidate whose helper manifests this evidence represents. This test directory is evidence only; it is not a contract authority and does not replace tracking the exact lockfiles beside the real helper sources in ores-cli.
